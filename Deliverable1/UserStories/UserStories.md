# User Stories

User stories from the platform's users.

> As a [role], I want [capability], so that [benefit]

| ID  | Description |
| --- | ----------- |
| 1   | As a student, I want to register, so that I can reserve food. |
| 2   | As a student, I want to log in, so that I can have access to the app under my personal account. |
| 3   | As a student, I want to browse available food, so that I can reserve the food I want. |
| 4   | As a student, I want to filter the available food, so that I can see the food that fits my needs. |
| 5   | As a student, I want to save providers in a favorites list, so that I see the offered food first. |
| 6   | As a student, I want to reserve food, so that it's kept for me until pickup. |
| 7   | As a student, I want to view my reservations, including past and cancelled ones, so that I know when and where to pick up. |
| 8   | As a student, I want to receive notification when a favorite provider makes food available, so that I don't miss out. |
| 9   | As a student, I want to access the provider's contact information, so that I can share suggestions, feedback or complaints. |
| 10  | As a student, I want to be able to cancel a reservation, so that in case of emergency the food is freed for other students. |
| 11  | As a student, I want to report issues and bugs with the app, so that maintainers can improve it. |
|     |                       |
| 12  | As a provider, I want to register my shop, so that I can offer left-over food to students. |
| 13  | As a provider, I want to log in, so that I can have access to the app under my shop account. |
| 14  | As a provider, I want to upload listings to the platform, so that students can see and reserve the food. |
| 15  | As a provider, I want to upload listings to the platform but make them invisible to students, so that I can plan ahead. |
| 16  | As a provider, I want to remove listings (including ones already reserved by students), so that listings can stay up to date. |
| 17  | As a provider, I want to view all my listings and the reservations for each listing, so that I stay updated with food flows. |
| 18  | As a provider, I want to set my shop details (location, pickup window, contact) so that students know where and when to pick up. |
| 19  | As a provider, I want to mark a portion as collected, so that I can keep track of food reserves. |
| 20  | As a provider, I want to restrict a student who repeatedly doesn't show up, so that they can no longer block portions for others. |
| 21  | As a provider, I want to set a limit on pickup amount per student per day, so that I can prevent abuses from students. |
| 22  | As a provider, I want to specify the amount of each available food, so that students can't reserve more food than available. |
| 23  | As a provider, I want to report issues and bugs with the app, so that maintainers can improve the app. |
|     |                       |
| 24  | As a maintainer, I want to approve or reject provider registrations, so that only real campus providers can list food. |
| 25  | As a maintainer, I want to delete a provider, so that the list of providers stays up to date. |
